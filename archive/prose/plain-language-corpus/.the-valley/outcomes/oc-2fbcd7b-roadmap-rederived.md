# The roadmap is derived from the user scenarios

The [roadmap](../../design/roadmap.md) was organized around the
[user scenarios](../../design/user-scenarios.md), with each phase identifying the scenarios it
establishes.

This completed outcome followed the requirements work in
[[oc-49555c7]](oc-49555c7-requirements-from-ladder.md). It provided a dedicated phase for agent
contributions and placed knowledge-graph work where the relevant scenarios require it.

Further roadmap changes should preserve the connection between planned work and the user need it
serves.
