# Valley terminology replaces the earlier group terminology

The current name for a collection of projects under shared policy is **valley**, as decided in
[[dcr-8f069dd]](dcr-8f069dd-valley-is-the-unit.md). This node is superseded.

The current decision covers the valley's repository, shared verification policy, identity registry,
and integrator principal. [[dcr-5da1f36]](dcr-5da1f36-project-is-repo.md) defines the project below
it as one Git repository, and [[dcr-9b5da04]](dcr-9b5da04-hosts-serve-isolated-valleys.md) describes
how hosts serve valleys.

Changing prose does not rename public module options or other interfaces. Those changes need an
explicit migration and compatibility review, as required by
[[dcr-8f069dd]](dcr-8f069dd-valley-is-the-unit.md).

The broader proposal for cooperation between valleys is in
[[ida-8482624]](../ideas/ida-8482624-federation-groups.md).
