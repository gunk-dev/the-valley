# Run provenance supplies the record needed for evaluation

[[ida-45178f6]](ida-45178f6-agent-identity-is-provenance.md) now contains the proposal for using
recorded run inputs as the basis of evaluation. This node is superseded.

The idea is to repeat real work while varying a model, prompt, or tool environment, then compare the
resulting trajectories and outcomes. A trustworthy input record makes the comparison interpretable
even when execution is not deterministic.

[[ida-d2dc957]](ida-d2dc957-attestations-ride-on-a-transparent-leaf.md) explores commitments that
can authenticate large or private inputs without publishing them.
